# Image slots

Generated by `scripts/build_images.py`. Do not hand edit the SVG files, they
are overwritten on every build.

Every slot below is generated as an SVG plate by scripts/build_images.py and listed in docs/assets/img/MANIFEST.md. To use a photograph instead, save it at the stated dimensions with the same basename and change the extension in the page markup. Alt text is content, not decoration, so it travels with the slot rather than the file.

## Replacing a plate with a photograph

1. Crop the photograph to the exact dimensions in the table below. The pages
   set `width` and `height` on every image, so a different ratio will letterbox
   or shift the layout.
2. Save it into `docs/assets/img/` as `<id>.webp` or `<id>.jpg`.
3. Change the extension for that slot in `scripts/pages/` and rebuild. The alt
   text lives in `content/images.json` and does not need to change.
4. Delete the matching `.svg` so it is clear which slots are still placeholders.

The `diagram` slot is artwork rather than a stand-in and should be kept.
